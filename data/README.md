# Dataset

## Source

NYC Open Data — 311 Service Requests from 2020 to Present

Official source:
https://data.cityofnewyork.us/Social-Services/311-Service-Requests-from-2020-to-Present/erm2-nwe9

## Analysis Period

September 1, 2025 – November 30, 2025

The project uses a three-month autumn period rather than the complete historical dataset to keep the analysis focused and manageable.

## Purpose

The dataset is used to analyze NYC 311 service request volume, operational patterns, resolution performance, and service-level performance.

## Important Note

The original NYC Open Data dataset is continuously updated. This project uses a fixed extract covering the analysis period above so that the analysis remains reproducible.
